MRS local test

The app does not load this file. Copy it to local-test-config.txt and fill the
account and Gemini key below for testers. Database setup and how to start the
app are in README.md. Copy the Gemini line into mrs/local.properties.

1. Install AWS CLI v2.32.0 or later.

2. Once, add this block to ~/.aws/config
   (Windows: %USERPROFILE%\.aws\config):

[profile mrs-admin]
region = ap-southeast-1
output = json
login_session = arn:aws:iam::133857166188:user/mrs-admin

3. Before a test session that changes the catalog or calls Verify for SES:

aws login --profile mrs-admin

aws sts get-caller-identity --profile mrs-admin
# expect: arn:aws:iam::133857166188:user/mrs-admin
